# План — Caravan Lean

Мета: показати власнику магазину, як виглядає **свій** застосунок замість сайту в браузері, — щоб він вирішив, чи є сенс робити справжній.

## Етап 1 — демо на даних із сайту (зараз)

1. Репо, меню телефона, CI — за шаблоном faric-ua.
2. Розвідка сайту на GitHub (`site-probe.yml`): движок, як влаштовані групи/товари, чи є карта сайту / API / фід.
3. Парсер (`catalog.yml`): групи → підгрупи → товари (назва, фото, ціна, стара ціна, наявність, артикул, опис, характеристики) → `catalog.json`.
4. Застосунок v0.1: плитки груп, група з підгрупами й сортуванням, картка товару (галерея, ціна, «У кошик», живе оновлення ціни з сайту),
   пошук, кошик, демо-оформлення, «Ще» з поясненням для замовника.
5. Фірмові кольори й логотип магазину в `Palette.kt` / значок — після розвідки.

## Етап 2 — якщо замовник погодиться

- Сервер магазину віддає каталог у форматі `catalog.json` (або своєму — тоді адаптер у `data/`), прямо з бази: ціни й залишки в реальному часі.
- Замовлення з застосунку — у їхню базу/CRM; «Мої замовлення», статуси.
- Вхід покупця, обране, push-сповіщення (знижки, «з'явилось у наявності»).
- Публікація в Google Play під брендом магазину.

## Що міняється між етапами

Лише джерело даних (`data/CatalogRepo.kt`): `BundledSnapshot`/`LiveProduct` → `RemoteJson(їхній сервер)`. Екрани ті самі.
