# Caravan Lean

Демо Android-застосунку для інтернет-магазину **shop.caravan-lean.com.ua**: каталог плитками (групи → підгрупи → товари),
картка товару з галереєю, пошук, кошик і демо-оформлення — **своїми екранами, без браузера**.

- Зараз дані — з сайту: GitHub Actions парсить сайт (`scripts/scrape_catalog.py`) у `catalog.json`; ціну й наявність товару
  застосунок ще й сам перевіряє на сайті, коли відкриваєш його картку.
- Далі — прямий доступ до бази магазину: той самий формат `catalog.json` віддає їхній сервер (`docs/PLAN.md`).
- Власник: faric (`faric-ua`), працює з телефона через Termux-меню — `docs/PHONE_SETUP.md`. Правила для асистента — `CLAUDE.md`.

Android 8+. Kotlin, без Compose.
